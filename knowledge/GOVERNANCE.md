# Desktop knowledge governance — baseline v1.0 (effective only after owner-approved merge)

The approved default branch is the source of truth for public build and release integration. For cross-repository tasks, authorized maintainers must independently consult the current approved source-repository instructions via permitted access; do not copy those instructions here. If access is unavailable, stop the affected cross-repository task. No private source, rules, logs, customer information, secrets or internal references may appear in public records, PRs, artifacts or logs.

Before work: identify the approved main commit, read AGENTS.md, this policy and the relevant existing build workflow. Work on a separate branch. Reconcile concurrent changes before integration and re-run applicable checks.

After work: record the cause, scope, evidence, tests and reusable lesson in a new JSON record under knowledge/records/ for every behavioral, source, configuration, test or workflow change PR. Use the template. A one-off or no-reusable-lesson disposition is permitted with a reason. Do not treat new observations as effective rules. Propose explicit changes to this policy or other canonical public-safe instructions only when the lesson is general, tested, conflict-free and approved. Preserve superseded revisions in Git. Approval of an owner-reviewed PR activates the approved rules; a record alone is not an instruction. Routine changes may be proposed independently; changes to licensing, security, release authority or contractual requirements require explicit owner approval.

Keep existing build/release boundaries. A blank version is a test build; versioned publication is a release and requires owner authorization. Do not dispatch builds, publish releases, alter token scopes or expose secrets merely to capture knowledge. Validate changed build logic in a safe test environment before release. Coordinate cross-repository changes with public-safe source revision/release metadata only. Report failures and tests not run. Do not merge into main without owner authorization.
